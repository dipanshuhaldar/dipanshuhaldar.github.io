# Portfolio Site — Deploy to GitHub Pages

## Steps
1. Create a new GitHub repo named exactly: `<your-github-username>.github.io`
   (e.g. if your username is `dipanshuhaldar`, the repo must be named `dipanshuhaldar.github.io`)
2. Upload both files from this folder (`index.html` and `Dipanshu_Haldar_Resume.pdf`) to the root of that repo.
3. Go to repo Settings → Pages → confirm source is set to the `main` branch, root folder.
4. Your site will be live at `https://<your-github-username>.github.io` within a minute or two.

## To update later
- Edit `index.html` directly (all CSS/JS is inline in one file — no build step needed).
- To swap in a new resume, just replace `Dipanshu_Haldar_Resume.pdf` with the same filename, or update the two `href="Dipanshu_Haldar_Resume.pdf"` links in index.html if you rename it.
